# Real-Time Video Frame Processing and Image Manipulation

## **Objective**
Develop a structured and well-documented Python notebook that:
- Captures video frames from the default webcam.
- Applies multiple filtering techniques.
- Performs basic image manipulations on selected frames.

The goal is to practice **real-time image processing**, enhance coding organization, and understand the practical application of computer vision techniques.

---

## **Task Description**

### **1. Video Capture**
- Use **OpenCV** to access the default camera and capture video frames in real-time.

### **2. Filtering Techniques**
- Apply at least **three different image filters** (e.g., Gaussian Blur, Edge Detection, Grayscale) to the captured frames.

### **3. Frame Saving**
- Save a selection of processed frames locally (e.g., every **30th frame**).

### **4. Image Manipulation**
- Perform basic image manipulations (e.g., **rotation, cropping, flipping**) on the saved frames.

### **5. Code Structure and Documentation**
- Ensure the notebook uses **well-organized code cells and Markdown cells** to explain each step.
- Use **efficient and concise code** while maintaining clarity and functionality.

---

## **Technologies Used**
- **Python 3.11.0**
- **OpenCV** for image and video processing.
- **Matplotlib** for visualization.
- **NumPy** for numerical operations.

---

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
2. Run the Notebook:
